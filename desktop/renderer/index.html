Stick builder

Build your ReviveBench stick

This wizard writes the guided bench environment onto a USB stick: a bootable Linux live image plus the repair payload. A tech then boots the stick, follows the on-screen bench flow, and consumes one license code per verified device unlock.

Before you start

  • ✓ USB stick, 8 GB or larger — everything currently on it will be erased.
  • ✓ Internet connection — license codes are checked online (steps 2 and later on the bench).
  • ✓ A supported 32-bit iOS device — v1 is proven on iPad mini 1 (iPad2,5), iOS 9.3.5.
  • ! One code = one unlock — codes burn only after a verified successful unlock.

Step 6

✓ Stick ready

The stick now has two parts: the bootable Linux image and the REVBENCH data partition with the bench tool and payload.

Boot it on the repair bench

  1. Reboot the bench PC with the stick inserted.
  2. Spam F12 at the power-on screen until the boot menu appears.
  3. Pick the entry that starts with UEFI: and the stick's name.
  4. Choose Start Linux Mint and wait for the desktop.
  5. Open the REVBENCH drive in Files, then double-click start-bench.sh (fallback: right-click → Run in terminal).
  6. The bench opens at http://127.0.0.1:8777 — follow the on-screen flow.
If the boot menu does not appear or Mint refuses to start

Reboot → F2 into BIOS → disable Secure Boot → save & exit → retry F12. Most shop boards need this once; the setting persists.
